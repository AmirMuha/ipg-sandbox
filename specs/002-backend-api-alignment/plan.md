# Implementation Plan: Backend API and Dashboard UI Alignment

**Branch**: `002-backend-api-alignment` | **Date**: 2026-10-03 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/002-backend-api-alignment/spec.md`

## Summary

Align the Iranian Payment Gateway Sandbox engine (FastAPI + SQLAlchemy) with the bilingual Next.js dashboard UI by resolving all functional and data gaps:
1. **Interactive & Automated Simulation**: Implement `POST /api/v1/transactions/simulate` returning the canonical `checkout_url`, with support for both interactive hosted portal testing and one-click instant completion; connect to `SimulateModal.tsx` in the dashboard.
2. **System-Wide Analytics & Funnel Overview**: Implement `GET /api/v1/analytics/overview` computing project-wide volume, success rate, status breakdown, and lifecycle conversion funnel stages (Initiated → Hosted → Callback → Settled) via SQL aggregation; update `StatCards.tsx` to display true project totals.
3. **Transaction Search & Pagination**: Add free-text search (`q`) and multi-criteria filters (`status`, `adapter`, date range) to `GET /api/v1/transactions`; add filter toolbar and pagination controls in the dashboard transactions view.
4. **Webhook Diagnostic Ping**: Implement `POST /api/v1/project/webhook-ping` with strict 3-second timeout to test receiver reachability; add test action and project webhook URL configuration to the dashboard.
5. **Transaction Lifecycle Actions**: Include `checkout_url` in transaction bodies, link to hosted checkout from detail pages, and expose individual transaction deletion with cascade removal.

## Technical Context

**Language/Version**: Python 3.12 (Engine), TypeScript 5.4+ / Node 20+ (Dashboard)

**Primary Dependencies**:
- Engine: FastAPI, SQLAlchemy 2.0 (asyncpg / aiosqlite), Alembic, Pydantic, httpx
- Dashboard: Next.js 14.2+ (App Router), next-intl 3.12+, Tailwind CSS 3.4+

**Storage**: PostgreSQL 16 (production docker compose), SQLite with `aiosqlite` (in-memory / local smoke test runs)

**Testing**:
- Engine: `pytest` with `pytest-asyncio` and `httpx.ASGITransport`
- Dashboard: Node 18+ native test runner (`node --test`), Playwright smoke tests
- Monorepo: `pnpm run test` and `pnpm run lint` via Turborepo

**Target Platform**: Local developer machines via Docker Compose and host processes (`pnpm dev`, `poe dev`)

**Project Type**: Multi-tier Web Application (FastAPI engine + Next.js SSR dashboard)

**Performance Goals**:
- `GET /api/v1/analytics/overview`: < 10ms execution time across 1,000 transactions
- `GET /api/v1/transactions` with `q`: < 20ms across 1,000 transactions
- `POST /api/v1/project/webhook-ping`: <= 3.0s strict timeout

**Constraints**:
- Bounded history cap: 1,000 transactions per project (FIFO purge)
- Local self-host: zero external network dependencies
- Bilingual parity: Persian (RTL) and English (LTR) interfaces

**Scale/Scope**: 1 shared project in local mode; multi-tenant isolation preserved for demo mode; 3 supported gateway adapters (Zarinpal, IDPay, Behpardakht).
