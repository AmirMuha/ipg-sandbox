# Data Model: API Key Authentication

## Entities

### `ApiKey`
Represents an API key generated by a user.

**Fields**:
- `id` (UUID, Primary Key): Unique identifier for the key record.
- `user_id` (UUID, Foreign Key): The user who owns this key.
- `name` (String, max 255): Descriptive name provided by the user.
- `key_hash` (String): SHA-256 hash of the full token (e.g., `hash("ipg_key_...")`). Used for authentication lookup.
- `last_four` (String, length 4): The last 4 characters of the token in plaintext for UI display.
- `created_at` (DateTime): When the key was created.
- `last_used_at` (DateTime, nullable): Updated when the key is used to authenticate a request.
- `revoked_at` (DateTime, nullable): If set, the key is invalid.

**Indexes**:
- Unique index on `key_hash` for fast authentication lookup.
- Index on `user_id` for listing keys in the UI.

## State Transitions
- **Active**: `revoked_at` is null.
- **Revoked**: `revoked_at` is set. Terminal state.
